# Motexa

Motexa is an intelligent vehicle ownership and automotive services platform.

## Current stage

Product definition and documentation.

## Core MVP

- Digital Garage
- AutoAI
- Specialist marketplace
- Service requests
- Quotes
- Booking/job tracking
- Service history
- Reviews
- Admin management

## Documentation

See the `docs/` directory.

## Working process

1. Define the product.
2. Document requirements.
3. Design user journeys.
4. Prototype UI with Google Stitch.
5. Design AutoAI.
6. Design architecture/database/API.
7. Implement incrementally.
8. Test continuously.
9. Validate assumptions with real users when possible.
10. Expand based on evidence.

## Important

The current market assumptions and seed data are placeholders until validated through real customer/provider research.
