# Motexa — Product Constitution

These principles govern product and engineering decisions.

1. Safety takes priority over convenience.
2. AutoAI must never present uncertain automotive assessments as confirmed diagnoses.
3. High-risk automotive situations should escalate toward qualified professional inspection.
4. Sensitive personal information should be minimized, protected, and retained only when justified.
5. A provider's verification status must be truthful and explainable.
6. Features must solve a defined user problem; novelty alone is not sufficient.
7. The MVP must remain focused.
8. Architecture should support future expansion without premature complexity.
9. Assumptions must be labeled as assumptions until validated.
10. Real user feedback should supersede founder assumptions when evidence is available.
11. AI should augment human expertise rather than falsely replace it.
12. The vehicle is a first-class domain object.
13. Third-party integrations should be abstracted where practical so providers can be changed later.
14. Security, testing, observability, and maintainability are product requirements, not afterthoughts.
15. Every major feature should have a measurable reason for existing.
