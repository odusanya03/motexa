# Motexa — Screen Inventory

## 1. Purpose

This document defines the screens required for the Motexa MVP and identifies their purpose, user type, and primary actions.

The inventory is intentionally focused on the MVP. Additional screens can be introduced as the product expands.

---

# 2. User Types

The initial application supports:

- Customer
- Automotive Provider
- Administrator

Future roles may include:

- Inspector
- Tow Operator
- Fleet Manager
- Parts Supplier

---

# 3. Customer Screens

## 3.1 Landing Page

### Purpose

Introduce Motexa and explain its primary value proposition.

### Primary actions

- Get started
- Sign in
- Ask AutoAI
- Find a specialist

---

## 3.2 Sign Up

### Purpose

Allow users to create a Motexa account.

### Elements

- Name
- Email
- Phone
- Password or authentication provider
- Terms acceptance

### Primary action

**Create Account**

---

## 3.3 Login

### Purpose

Allow existing users to authenticate.

### Elements

- Email/phone
- Password
- Forgot password
- Social authentication where supported

---
