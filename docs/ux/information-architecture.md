# Motexa — Information Architecture

## 1. Purpose

This document defines how information, features, and navigation are organized within Motexa.

The architecture should make it easy for users to move from:

Problem → Understanding → Recommendation → Action → Resolution

The structure should remain simple enough for the MVP while allowing the platform to expand later.

---

# 2. Core Product Structure

Motexa is organized around six major areas:

1. Home
2. AutoAI
3. Vehicles
4. Services
5. Activity
6. Profile
