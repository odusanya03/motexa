# Motexa — AutoAI Diagnostic Workflow

## 1. Purpose

This document defines how AutoAI should guide a user from an automotive problem to an appropriate next action.

The workflow is designed to:

- Understand the user's problem
- Collect relevant vehicle information
- Identify symptoms
- Assess safety
- Generate possible causes
- Recommend appropriate checks
- Provide safe DIY guidance where appropriate
- Recommend professional assistance when necessary
- Connect the user to Motexa services

AutoAI provides preliminary guidance and does not replace physical diagnosis by a qualified automotive professional.
